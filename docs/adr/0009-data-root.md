# ADR-0009 — Единый корень данных и изоляция секретов

**Статус:** accepted
**Источник:** `skills/wireguardgui-architecture/`, [constitution](../../plan/constitution.md) I7
**Связано:** ADR-0003, ADR-0008

## Контекст

Приложение хранит приватные ключи (в импортированных конфигах), настройки UI,
параметры split routing и кэши сетевых источников. Ключи — самый чувствительный
артефакт: их утечка означает компрометацию туннеля.

## Решение

Единственный корень — `~/.local/share/wireguard-gui/`:

| Данные | Путь |
|--------|------|
| Конфиг профиля (секреты) | `profiles/{id}/wireguard.conf` |
| Настройки приложения | `settings.json` |
| Кэши источников | `youtube-*.json`, `twitch-stream-hosts-cache.json` |

Секреты вне этого каталога не хранятся и не логируются (I7).

## Альтернативы

- Разнести config/data по XDG (`~/.config` + `~/.local/share`) — привычнее для Linux, но дробит бэкап и усложняет «снести всё».
- Хранить ключи в системном keyring — безопаснее, но тянет зависимость и ломает переносимость профилей.

## Последствия

+ Один каталог для бэкапа и полного удаления; понятное место для инцидента «где мои ключи».
− Миграции JSON-схем делаются вручную (версии файлов не предусмотрены).
− Права на каталог явно не ужесточаются (полагаемся на umask пользователя), keyring не используется.
