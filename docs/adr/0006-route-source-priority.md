# ADR-0006 — Источники маршрутов: порт с приоритетом и общим лимитом

**Статус:** accepted
**Источник:** `skills/wireguardgui-split-routing/`, [constitution](../../plan/constitution.md) I9
**Связано:** ADR-0005, ADR-0007

## Контекст

Маршруты приходят из источников разной природы и надёжности: статические CIDR (Telegram,
Cloudflare), bulk-префиксы Google для YouTube, DNS-резолв пользовательских доменов,
discovery Twitch-хостов. Список при этом нужно ограничивать — тысячи маршрутов в nft и
в правилах не бесплатны.

## Решение

Порт `ISplitRouteSource` (`IsEnabled`, `CollectAsync`), оркестрация — `SplitRouteBuilder`:

1. собрать CIDR всех включённых источников;
2. упорядочить по `Priority` — static CIDR (0) → DNS (1) → YouTube bulk (2);
3. усечь до `maxRoutes` (default 200), отбрасывая низкоприоритетное.

Новые источники добавляются реализацией порта и регистрацией в билдере, без правок UI.

## Альтернативы

- Лимит на каждый источник вместо общего — предсказуемее по составу, но оставляет дыры при малом лимите (вынесено в шаг 15-6 как уточнение).
- Без приоритетов — при усечении отрезался бы произвольный источник, включая критичный для пользователя.

## Последствия

+ Поведение под лимитом детерминировано и объяснимо пользователю.
− Уже случалась обрезка CDN YouTube (коммит `ff1a72d` поднимал лимит) — цена общего лимита.
− Настройка лимита не выведена в UI (шаг 15-5), квот на источник нет (15-6).
